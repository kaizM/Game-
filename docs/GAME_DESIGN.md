# Harborlight game design — production baseline

## Identity

Harborlight is an original, coastal urban roleplay game about building a life in a working city. Its starting district is North Pier: Lantern Square, South Market, Foundry Row, the Old Ferry Office, the waterfront, and a neighborhood garage. The production identity, map, text, models, interface, and systems are Harborlight-owned or properly licensed.

## Player journey

Create a resident, learn movement and interaction, take a local job, walk or drive through the district, complete a multi-step activity, receive validated progress, save, and resume. Later milestones extend that foundation into owned vehicles, homes, work, public safety, businesses, factions, and social play. Each feature must connect to persistent player goals rather than stand alone as a menu.

## Release progression

1. Finish and profile one attractive, continuous mobile district.
2. Verify character movement, map/objectives, walking/driving transitions, three original job chains, garage progression, and save migration offline.
3. Add an authoritative shared world only after the networking stack and server model are verified.
4. Add economic, careers, property, faction, and social systems behind tested server-side rules.
5. Expand districts and production content after the first district meets mobile performance and art gates.

## Current versus planned scope

The current game is offline-first, with three original job chains and an eight-entry garage. A bounded server-authoritative multiplayer foundation supports authenticated loopback joins, movement and interaction acknowledgments, reconnect, and two-client avatar visibility on the earlier 14.24 km² layout. The current 24.70 km² map passes layout and spawn-coordinate smoke checks, but expanded-map multi-client traversal remains unverified. This is not production multiplayer: remote transport, distributed spawn validation, vehicles/NPC replication, and scale remain unverified. Police careers, gangs, combat, housing, player trade, social chat, and player-owned businesses remain future features and must not be represented as complete.

## Content boundary

Use original Harborlight names, layouts, mission writing, signs, UI, characters, and world design. Reference games can inform broad genre expectations only. REA package observations cannot be converted into copied source, extracted maps, or protected assets.
